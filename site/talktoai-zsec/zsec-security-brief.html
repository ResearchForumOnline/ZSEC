03 / Safety Boundary ZSEC security brief

A safer updater starts by saying what it does not do.

ZSEC does not replace monitoring, backups, firewall policy, SSH key hygiene, or incident response. The public feed is data, not authority to execute remote commands.

  • No browser-supplied upstream URLs.
  • No public secrets.
  • No feature-upgrade automation.

04 / Operational Flow ZSEC security brief

The workflow is easy to explain.

Install ZSEC, confirm access and backups, run local status checks, review advisory TODOs, apply normal OS security updates, and keep a record of what changed.

  • Normal Linux package managers.
